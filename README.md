# 藏文化学习交流平台

Tibetan Culture Learning and Communication Platform

## 项目简介

这是一个专注于藏文化学习与交流的在线平台，旨在传播和保护藏族优秀传统文化，为学习者提供全面的学习资源和交流空间。

## 功能特性

### 1. 藏文化知识库
- 📚 历史文化：藏族历史、重要事件、历史人物
- 🎨 艺术文化：唐卡、藏戏、音乐、舞蹈
- 🏛️ 宗教信仰：藏传佛教、寺庙文化、宗教仪式
- 🏔️ 地理风情：西藏地理、民俗风情、节日庆典
- 📖 文学典籍：藏文经典、诗歌、史诗

### 2. 学习资源
- 📝 藏语学习：基础教程、语法讲解、发音指导
- 🎬 视频课程：文化讲座、纪录片、教学视频
- 🎵 音频资源：藏语听力、传统音乐、经文诵读
- 📚 电子书籍：文化读物、学习教材、研究论文

### 3. 交流社区
- 💬 讨论区：文化交流、学习心得、问题解答
- 👥 用户互动：评论、点赞、分享
- 📝 文章投稿：用户分享学习经验和研究成果

### 4. 特色功能
- 🔍 智能搜索：快速查找相关内容
- 🌓 深色模式：护眼模式切换
- 📱 响应式设计：支持移动设备访问
- 🌐 多语言支持：中文、藏文、英文

## 技术栈

- HTML5
- CSS3
- JavaScript (原生)
- 响应式设计

## 快速开始

### 本地运行

```bash
# 使用 Python 启动本地服务器
python3 -m http.server 8000

# 或使用 npm
npm run dev
```

然后在浏览器访问：`http://localhost:8000`

### 部署

项目为纯静态网站，可部署到：
- GitHub Pages
- Netlify
- Vercel
- 任何静态网站托管服务
